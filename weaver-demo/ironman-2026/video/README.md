# Day1 的敘事稿（給 story-to-handdrawn-video 用）

`day01-story.txt` 是把 Day1 抽成一條可以畫出來的敘事線：一隻 agent 被換到陌生環境、
四次查詢全空、最後報出一個精確到個位數卻是憑空生出來的數字。

**為什麼不直接餵 `day01.md`。** 那支工具吃的是中文敘事，會自動斷句成分鏡再生圖。
文章裡的 mermaid、PromQL、JSON、表格、終端輸出都會被當成句子，分鏡出來是一堆
畫不出來的東西。所以先抽敘事線，一句一個畫面。

## 稿子的寫法

- 一句一個分鏡，每句都要是**畫得出來的畫面**，不要抽象名詞堆疊。
- 數字用中文（八百一十四、六十、四點五），生成模型畫阿拉伯數字常常糊掉。
- 專有名詞盡量減到最少，`Prometheus / Loki / Tempo` 統一講成「指標、日誌、追蹤紀錄」。
- 收在一句結論上，不要收在數字上。

## 跑之前要有的東西

Node 20+、Python 3.10+、FFmpeg、Chrome 都要有（這台上都有）。
圖像生成需要 Codex Image2，或明確指定時吃 `OPENAI_API_KEY` —— **這台目前沒有設**，
那是唯一還缺的東西。

輸出是 1080×1440 直式無聲 MP4，適合社群短影音導流，不適合當文章內文插圖。

## 風格

那支工具有 20 種手繪風格。這個系列的調性是「所有輸出都是真跑出來的」，
選太可愛的風格會削弱可信度，建議挑版畫或鉛筆那類冷一點的。
