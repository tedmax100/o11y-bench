# 待標清單（11 筆）— 2026-08-26

標註只能由人或 grader 填，系統自己標的不算數。這份把每一筆整理成一分鐘判得完的形式。

## 先講難聽的：標註不是瓶頸

這 11 筆裡 **6 筆是排練**（`drill=true`）、**3 筆是 chat 問答**。真正能進真實 culprit 曲線的只有 **2 筆**。

所以全部標完，真實那條曲線是 4 → 6，離門檻 20 還很遠。它只解得掉一個條件：
`band n (conf≥0.8) ≥ 3`，現在 2，標完那兩筆就過。

**`labeled ≥ 20` 只有一條路：跑出更多真實事故 run。** 那需要更多事故劇本。

## 怎麼標

Grafana → Apps → AIOps → **Todo**，或用 CLI：

```bash
kubectl -n demo exec deploy/aiops-agent -- python -m app.calibration label <fp> --correct   # 或 --wrong
```

`grading_mode` 兩種：**culprit**（兇手指對了嗎，校準門只讀這種）、**inconclusive**（沒事的時候有沒有適當保留）。
把 inconclusive 標成 culprit 就是 Day29 那個 MCE 1.0 的坑。
